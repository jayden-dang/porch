# Architecture Decision Records

One file per hard-to-reverse decision, written by `define-domain`.

Naming: `NNNN-kebab-title.md`. An ADR states the context, the decision, and the
consequences — not the implementation. Superseded ADRs stay in place with a
pointer to the ADR that replaced them; they are not deleted.

Standing rules that every feature must respect are **not** ADRs — they live in
the `ARCH-N` spine at [../architecture/INDEX.md](../architecture/INDEX.md).
ADRs record a choice made at a point in time; invariants constrain all future
choices.
